PARALLEL PROCESSING BRANCHES
STAGE 3
Cloud Detection Head
3-Block Lightweight U-Net (32 → 64 → 128 channels)
  • Architecture: Lightweight 3-block U-Net operating at feature scales of 32, 64, and 128 channels.
  • Supervision: Trained using CloudSEN12+ annotated cloud masks and pseudo-labelled confidence maps.
  • Output: Generates continuous cloud confidence probability maps and binary cloud masks with calculated cloud coverage percentage.
STAGE 4 (CORE)
SPANet Generator
Encoder → Swin Transformer Bottleneck → Decoder + SAM Gates
  • Encoder: 4 Convolutional DownBlocks expanding channel resolution from 64 to 512 channels to extract multi-scale spatial features.
  • Swin Transformer Bottleneck: 2 Swin Transformer blocks (dimension = 512, window size = 8, attention heads = 8). Captures global image context, enabling the network to reconstruct heavily obscured cloud regions by synthesizing information from distant cloud-free land cover.
  • Decoder with SAM Gates: 4 UpBlocks (512 → 64 channels) gated by Spatial Attention Modules (SAM) on every skip connection to concentrate reconstruction capacity specifically on cloud-affected pixels.
↓
STAGE 5
Cloud-Free GeoTIFF Output
Full 4-Band Reconstructed Raster · Preserved Geo-Metadata · REST API & GIS Ready

Multi-Scale Discriminator & Loss Formulation

Mathematical objectives driving spatial detail and spectral consistency

DISCRIMINATOR D1

256×256 PatchGAN

Evaluates local pixel patches to enforce high-frequency edge sharpness and fine texture realism.

DISCRIMINATOR D2

128×128 PatchGAN

Evaluates downsampled global views to guarantee macro-level color balance and tonal coherence.

COMBINED LOSS OBJECTIVE
L_total = L1 + L_GAN + 0.10 × L_attn + 0.10 × L_perceptual + 0.05 × L_spectral
L1 Loss

Measures pixel-by-pixel mean absolute difference between reconstructed output and ground truth.

L_GAN Loss

Adversarial score from D1 and D2 forcing the generator to produce realistic ground distributions.

0.10 × L_attn

Ensures the Spatial Attention Modules accurately focus weights on cloud-affected pixels.

0.10 × L_perceptual

VGG-16 feature map similarity (conv2_2 and conv3_3 layers) capturing high-level visual structure.

0.05 × L_spectral

Per-band mean and variance consistency in non-cloud regions — preserving scientific spectral integrity for downstream satellite data processing.
